# Demo project

A fictional online storefront tracked with taskroll: three epics (checkout, catalog, platform) with work in every status, dependencies on tasks and on plain-language conditions, a bug, blockers, a custom `quarter` field, an `urgent` marker, comments, a debt list and an ideas list. The people and the project are made up.

It serves two purposes: it is the demo the top-level README points to, and it is the fixture the end-to-end tests in `e2e/` copy and drive. Change it through the CLI like any tracker, and run `taskroll index` here after a change to taskroll alters the generated files.
